# 红果短剧 v0.2.179

- 播放页时钟下方恢复"当前集/总集数"显示（如 `5/200`），位于右上角 HUD 容器内，与时钟同步显示/隐藏。
- 集数为纯展示：进入播放时从内存中的播放数据算一次，不含跳集输入、按钮焦点、遥控器数字键或任何定时器/跨线程调用，不会再引起播放卡顿。
- 集数未知时安全降级为 `1/--`，总集数未知显示 `--`。
- 自动清晰度的选档上限由 720P 提升到 1080P：片源提供高清档位时，"自动"将优先选用 1080P，投影仪/电视可直接获得全高清画质；全部档位超过 1080P 时仍回退到最高可用档。手动选择的清晰度不受影响。
- 标准版（Media3）：当设备硬件解码能力不足、自动切换到软件解码播放时，弹出"硬解能力不足，已切换软解播放"提示，约 3 秒后自动消失，不遮挡画面、不影响播放。每个播放会话最多提示一次；仅标准版生效，MPV 版不受影响。
- 时钟行为不变（WebView 系统时钟、HH:MM、每 30 秒刷新、无 Java 桥）；版本更新扫码、弹幕顶部 1/4 区域、Media3 主播放路径等功能保持不变。
- 本次发布包含标准版与 MPV 版，不提供 Android 5 兼容版。
