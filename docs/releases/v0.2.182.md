# 红果短剧 v0.2.182

本版为 v0.2.181 的构建修复版本，仅修复一处导致 Android 编译失败的回归，播放与功能行为与 v0.2.181 一致。

- 修复 v0.2.181 合入公告功能后，Android `PlayerBridge.Session` 丢失 `softwareFallbackNotified` 字段定义、而软解降级提示仍在引用它，导致的编译失败（`cannot find symbol`）。
- 为软解降级提示的源码检查补上「字段必须在 `Session` 中声明」的断言，防止合并再次只保留使用处而漏掉定义。
- 系统公告、播放保障与解析规则在线更新、Mac 全屏／小窗口崩溃与 Windows CPU 软解音频接缝修复等 v0.2.181 功能保持不变。
- 时钟、集数徽标、自动清晰度 1080P 封顶、同剧切集保留 Media3 播放器、更新二维码等功能保持不变。
- 本次发布包含标准版与 MPV 版，不提供 Android 5 兼容版。
