# 红果短剧 v0.2.182

- 新增默认播放规则自动更新，启动后台检查，也可在设置中手动检查，无需重启应用。
- 播放保障显示当前优先规则和版本；检查按钮始终可用，保留原有 JS 修复开关和回退逻辑。
- 更新播放取源的设备参数和签名，保留兼容编码及原生来源回退。
- 繁体界面支持剧名、简介等内容的本地转换，无需联网翻译。
- 修复 v0.2.181 合入公告功能后，Android `PlayerBridge.Session` 丢失 `softwareFallbackNotified` 字段定义、而软解降级提示仍在引用它，导致的编译失败（`cannot find symbol`）；并为该源码检查补上「字段必须在 `Session` 中声明」的断言。
- 系统公告、Mac 全屏／小窗口崩溃与 Windows CPU 软解音频接缝修复、时钟、集数徽标、自动清晰度 1080P 封顶、同剧切集保留 Media3 播放器、更新二维码等既有功能保持不变。
- 本次发布包含标准版与 MPV 版，不提供 Android 5 兼容版。
