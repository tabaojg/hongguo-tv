# 红果短剧 v0.2.175


- 播放时钟改为读取 Android 系统时间并每秒实时刷新，固定在右上角"连接状态"位置；播放时"已连接"隐藏、时钟常显。
- 时钟下方新增当前集/总集数（如 5/200）；点击集数徽标或使用遥控器数字键可输入集数直接跳转。
- 版本更新改为扫码：检测到新版本后展示更新二维码，手机扫码打开发布页自行下载安装，不再在电视端在线下载（仅 Android）。
- MPV 版保持原有播放方式不变。本次发布包含标准版与 MPV 版，不提供 Android 5 兼容版。

- 新增 My Music+ 应用推荐与下载安装入口。
- 优化侧栏焦点显示和桌面播放控制体验。
